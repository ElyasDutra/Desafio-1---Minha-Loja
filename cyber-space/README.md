## Sobre o projeto

A Cyber Space é uma loja fictícia de acessórios gamers criada
para praticar HTML, CSS e JavaScript.

A página apresenta três produtos e permite simular uma compra
informando a quantidade desejada de cada item. O sistema calcula
os subtotais, verifica a possibilidade de desconto e exibe
o resumo da compra.

## Produtos e preços

| Produto | Descrição | Preço |
|---|---|---:|
| Headset Pro | Som imersivo e microfone | R$ 150,00 |
| Teclado Mecânico | Precisão e conforto | R$ 250,00 |
| Mouse RGB | Design ergonômico e iluminação | R$ 100,00 |

Compras a partir de R$ 400,00 recebem 10% de desconto.

## Tecnologias utilizadas

- HTML5: estrutura da página.
- CSS3: identidade visual e responsividade.
- JavaScript: perguntas, cálculos, validações e resultados.
- Git e GitHub: versionamento e hospedagem do código.

## Como executar

1. Clone ou baixe este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` em um navegador.
4. Clique em **Simular compra**.
5. Informe a quantidade de cada produto.
6. Confira o resumo apresentado na tela.

Não é necessário instalar dependências.

## Testes realizados

- [ ] Comprar um único produto.
- [ ] Comprar quantidades de produtos diferentes.
- [ ] Informar zero para todos os produtos.
- [ ] Verificar o desconto em uma compra inferior a R$ 400,00.
- [ ] Verificar o desconto em uma compra de R$ 400,00 ou mais.
- [ ] Informar uma quantidade negativa.
- [ ] Informar um valor decimal ou texto inválido.
- [ ] Cancelar uma pergunta.
- [ ] Conferir se os preços do site correspondem aos do JavaScript.

Marque os testes somente depois de executá-los.

## Dificuldade encontrada e aprendizado

**Dificuldade:** Ao contrário de JavaScript e HTML, eu não possuía tanta familiaridade com CSS, mas, durante o desafio, aprendi mais sobre essa ferramenta de personalização e pude desenvolver o código com mais confiança.

**Aprendizado:** Aprendi a utilizar prompt() para receber dados,
Number() para converter valores, operadores matemáticos para
calcular subtotais e condicionais para verificar o desconto.

Também pratiquei a organização do projeto em arquivos separados
e a personalização da página com CSS.

## Uso de inteligência artificial

Utilizei o ChatGPT como apoio para estruturar o projeto, elaborar
uma proposta visual e compreender a lógica de cálculo da compra.

Adaptei o projeto para ser uma loja de acessórios para gamers e verifiquei o funcionamento executando testes no navegador.
